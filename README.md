# Altar Guardian (Хранитель Алтаря)

Проект игры в жанре RPG/стратегия по управлению ресурсами и обороне.

## Описание
Игрок берет на себя роль хранителя магического алтаря, который должен выстоять в условиях набегов существ из Пустоты.
